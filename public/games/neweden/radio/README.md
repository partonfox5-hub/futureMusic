# New Eden radio

Three original stations live in `src/game/radio.ts`. Each reel is over ten minutes of original talk, ads, news, and generated beds.

| Dial | Name | Genre | Culture |
|---|---|---|---|
| 98.4 | Plaza Gold | Brass yacht / city pop | Fountain clerks, Harbor gossip |
| 610 AM | Wiregrass | Barn folk / pedal steel | Farm reports, livestock names |
| 103.7 | Night Circuit | Vector synth | Spectre patrols, rim outlaws |

Playback is original: SpeechSynthesis reads the scripts, Web Audio sequences station-specific melodies, and the WAV loops in this folder (generated by `scripts/gen-radio-wav.mjs`) ride under the hour.

Y while in a cabin cycles Off → Plaza Gold → Wiregrass → Night Circuit → Off.
