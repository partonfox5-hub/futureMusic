# Short-fur material — 20.1.0

`fur-neutral-20.1.png` was created for this project using the built-in image generation tool on 2026-09-13. It is shared by the dog/cat coat shader, with breed colors supplied independently. No third-party photograph or animal model was downloaded. The original output is copied unchanged.

Prompt: “Seamless tiling neutral fur albedo texture for real-time 3D dog and cat coats in a Quest 3 game. One square texture image, edge-to-edge orthographic macro material swatch of natural very short, fine dense animal fur, realistic dense undercoat with individual thin tapered guard hairs, mostly gently flowing down the image with subtle irregularity. Neutral medium-light gray monochrome so the engine can tint different breeds. Flat cross-polarized diffuse lighting, even brightness everywhere, only microscopic hair shading. Thousands of fine individual strands, not thick locks. Tile without obvious seams; no large waves, clumps, folds, knit fabric, bare skin, bald patches, animal face or outline, border, labels, text or watermark. Keep contrast restrained.”

The texture is generated artwork; the in-game bodies remain procedural skinned geometry. Preview images in H6-tests show the actual renderer, not a generated depiction of gameplay.
